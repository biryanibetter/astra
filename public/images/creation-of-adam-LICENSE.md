# Creation of Adam — reaching hands

- Artist: Michelangelo Buonarroti (1475–1564), *The Creation of Adam*, c. 1511.
- Original photographic detail: 1400 × 1047 pixels, not the supplied reference screenshot.
- File page: https://commons.wikimedia.org/wiki/File:Creation_of_Adam_(Michelangelo)_Detail.jpg
- Original download: https://upload.wikimedia.org/wikipedia/commons/3/39/Creation_of_Adam_%28Michelangelo%29_Detail.jpg
- License/status checked 2026-10-22: **public domain**, PD-Art / PD-old-100-expired.
  Wikimedia identifies this as a faithful reproduction of a two-dimensional
  public-domain artwork. Michelangelo died in 1564. The file page explains
  jurisdiction-specific treatment of PD-Art reproductions:
  https://commons.wikimedia.org/wiki/Commons:Reuse_of_PD-Art_photographs
- Local derivative: `creation-of-adam-hands.webp`, 1400 × 640. Background isolated
  with manually traced silhouette masks, cropped vertically and desaturated
  for the silver dither rendering. Neither hand is repositioned,
  stretched or redrawn. The original fingertip gap is retained.
- Reproduction: `node scripts/prepare-creation-artwork.mjs`, with the original
  downloaded to `artifacts/creation-of-adam-source.jpg`. Uses Next.js's existing
  sharp dependency; no new package is required.

This image is artwork, not ASTRA event photography or reel footage.

`creation-dither-desktop.webp` and `creation-dither-mobile.webp` are lossless,
pre-rendered derivatives of this same public-domain source, generated by the
production Canvas2D renderer at time zero. Rebuild them with
`node scripts/generate-dither-first-frames.mjs` while the local app is running.
Only these processed dither assets are visible during SSR/no-JS/loading states;
the photographic derivative is exclusively an offscreen sampling input.
