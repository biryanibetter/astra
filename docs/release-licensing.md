# Licensing status for the Lenis 0.065 release

The project owner authorized an exception to the internal public-release hold
for this update to the existing GitHub repository and Cloudflare deployment.
The update does not add or change the reel media or the school dataset. This
exception does not verify redistribution rights or override any applicable law,
license, or platform rule.

- **Reel media:** The project records trace `public/media/astra-reel-loop.webp`
  and `public/media/astra-reel-still.webp` to `public/videos/video.mp4`.
  A separate source clip and poster remain in Git history. No redistribution
  grant was verified for either source or its derivatives.
- **Qatar school data:** `src/data/qatar-schools.json` uses the Ministry of
  Education and Higher Education's government, private, and specialized
  My School layers. The layer and catalog metadata do not specify a reuse
  license, and the exact layers could not be matched to a dataset covered by
  the [State of Qatar Open Data License](https://www.data.gov.qa/pages/license/).
  Source attribution is retained.
